## ✨🔥 𝐅𝐄𝐀𝐓𝐔𝐑𝐄𝐒 🔥✨

### 🏠🌈 Homepage — `index.html`
- 🎨 A colourful **Homework_Simulator.org** game-library design.
- 🔎 Search to filter the game cards.
- 🎮 Play Pitch Black Pack Pull in a pop-up.
- 💡 Example cards for future game ideas.
- ➕ The **Add a game** button adds a temporary placeholder card in the current browser session. It does **not** upload a game file or save the card permanently.

### 🖼️🌑 Complete card gallery — `pitch-black-card-gallery.html`
- 🎴 Browse all **120 numbered Pitch Black cards** with their card-front images.
- 🔎 Search by name or card number and filter by rarity or Pokémon vs. Trainer/Energy.
- 🌐 Card images load from a public image service, so an internet connection is needed.

### 🌑🎴 Standalone game — `pitch-black-pack-pull.html`
- 📦 Open packs and reveal a card!
- 📊 Tracks packs opened, special hits, and best streak during the current session.
- 🍀 Includes a special-hit roll with a target chance of **1 in 100 (1%)**.
- 🖍️ Uses simplified, fan-made visuals and emoji rather than official card scans.

## 🕹️💻 𝐇𝐎𝐖 𝐓𝐎 𝐏𝐋𝐀𝐘 💻🕹️

1. 📥 Download or clone this repository.
2. 🌐 Open `index.html` in a modern web browser.
3. 🎮 Click **Play now** on Pitch Black Pack Pull.
4. 📦 Press **OPEN PACK** and see what you pull!

✨ You can also open `pitch-black-pack-pull.html` directly.

🛠️ No build step or package installation is needed — the project uses HTML, CSS, and JavaScript.

## 🌍🚀 𝐏𝐔𝐁𝐋𝐈𝐒𝐇 𝐖𝐈𝐓𝐇 𝐆𝐈𝐓𝐇𝐔𝐁 𝐏𝐀𝐆𝐄𝐒 🚀🌍

1. 🐙 Open this repository on GitHub.
2. ⚙️ Select **Settings**, then **Pages**.
3. 🔧 Under **Build and deployment**, choose **GitHub Actions** as the source.
4. 📤 Push a change to `main` (or manually run **Deploy to GitHub Pages** from the **Actions** tab).
5. ⏳ Wait for the deployment workflow to finish, then visit the URL shown in the Pages settings or workflow deployment.

The workflow publishes the repository root directly; no build step is required. Every push to `main` publishes the latest site.

🔐 **Safety tip:** Never put passwords, access tokens, or other secrets in your repository.

## ➕🎮 𝐀𝐃𝐃 𝐌𝐎𝐑𝐄 𝐆𝐀𝐌𝐄𝐒 🎮➕

The homepage's **Add a game** button currently adds only a temporary placeholder card. To add another **playable** game to the published website:

1. 🧩 Add the new game's HTML file to the repository, such as `my-game.html`.
2. ✍️ Edit `index.html` and add a game card in the game grid.
3. 🔗 Link the card to the new game file.
4. 📤 Commit the changes to `main`.
5. 🚀 Wait for GitHub Pages to publish the update.

🖼️ If the game uses separate CSS, JavaScript, or image files, upload those too and keep the file paths correct.
